Quick start

가장 작은 학습 루프

모델, 손실, optimizer가 모두 같은 CUDA 장치에서 연결됩니다. CPU fallback은 없습니다.

import mytorch as mt

model = mt.nn.Sequential(
    mt.nn.Linear(2, 16), mt.nn.ReLU(), mt.nn.Linear(16, 1)
)
optimizer = mt.optim.AdamW(model.parameters(), lr=1e-3)

optimizer.zero_grad()
loss = mt.nn.functional.mse_loss(model(x), target)
loss.backward()
optimizer.step()

공통 규칙

GPU only

모든 forward, backward, optimizer state는 CUDA에 남습니다.

기본 dtype

Python 실수와 sequence는 별도 지정이 없으면 float32입니다.

명시적 CPU 복사

결과 확인은 Tensor.numpy() 또는 단일 원소의 item()을 사용합니다.

동적 autograd

requires_grad와 현재 gradient mode에 따라 실행 시점에 그래프를 만듭니다.
