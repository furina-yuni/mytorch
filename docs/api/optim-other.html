Optimization · mytorch.optim.other

ASGD, Rprop, Adafactor, Lion

평균화 SGD, 부호 기반 resilient update, factorized second moment, sign momentum 방식의 optimizer를 설명합니다.

MyTorch 0.7.08개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • Adafactor는 행렬 파라미터의 second moment를 행·열로 factorize해 state 메모리를 줄입니다.
  • Lion은 하나의 momentum state와 sign update, decoupled weight decay를 사용합니다.
  • Rprop은 gradient 크기 대신 연속 step의 부호 변화로 원소별 step size를 조절합니다.

기본 예제

optimizer = mt.optim.Lion(
    model.parameters(), lr=1e-4, betas=(0.9, 0.99),
    weight_decay=0.01,
)
