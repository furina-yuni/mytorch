Module과 기본 계층

Parameter 등록, 모델 상태, Module 컨테이너와 Linear·Flatten 같은 기본 구성요소만 모아 설명합니다.

MyTorch 0.13.027개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • Module 속성에 Parameter나 자식 Module을 대입하면 자동 등록되어 parameters()와 state_dict()에 포함됩니다.
  • train(), eval(), to(), zero_grad()는 등록된 자식과 Parameter를 재귀적으로 처리합니다.
  • Sequential, ModuleList, ParameterList는 Python container와 비슷하지만 내부 객체의 등록 상태를 유지합니다.

기본 예제

import mytorch as mt

model = mt.nn.Sequential(
    mt.nn.Linear(8, 32),
    mt.nn.ReLU(),
    mt.nn.Linear(32, 4),
)
print([name for name, _ in model.named_parameters()])

Signature
mytorch.nn.Parameter(data: 'Any', *, dtype: 'Any' = None, device: 'str | int | None' = None, requires_grad: 'bool' = True) -> 'None'

파라미터

인자타입기본값설명

dtype'Any'None결과 또는 파라미터의 dtype입니다. 생략 시 생성 규칙 또는 입력 dtype을 따릅니다.
device'str | int | None'NoneCUDA 장치입니다. 'cuda:N' 문자열 또는 정수 N을 사용하며 기본값은 cuda:0입니다.
requires_grad'bool'TrueTrue이면 실수 Tensor에 대해 자동미분 계산 그래프를 기록합니다.
