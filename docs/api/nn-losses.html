Neural network · mytorch.nn.modules

손실 함수 Module

회귀, 분류, 확률분포, ranking, metric learning과 segmentation 손실의 클래스형 API를 설명합니다.

MyTorch 0.9.021개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 손실 Module은 reduction과 weight 같은 설정을 생성자에 보관하고 forward에서 prediction과 target을 받습니다.
  • 분류 손실의 class-index target은 int64를 사용하고 BCE·회귀 손실은 일반적으로 입력과 같은 shape가 필요합니다.
  • reduction='none'은 개별 손실을 유지하며 'mean'과 'sum'은 역전파 가능한 scalar를 반환합니다.

기본 예제

import mytorch as mt

criterion = mt.nn.CrossEntropyLoss(label_smoothing=0.1)
logits = mt.randn(16, 4, requires_grad=True)
target = mt.tensor([0, 1, 2, 3] * 4, dtype=mt.int64)
loss = criterion(logits, target)
loss.backward()
