Optimization · mytorch.optim.optimizer

Optimizer 기반 클래스

파라미터 그룹, 공통 옵션 검증, gradient 초기화, GPU optimizer state의 기본 계약을 설명합니다.

MyTorch 0.9.09개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • params에는 Parameter iterable 또는 params 키를 가진 parameter-group dict iterable을 전달합니다.
  • 같은 Parameter를 여러 그룹에 중복 등록할 수 없으며 빈 그룹과 알 수 없는 옵션은 거부됩니다.
  • zero_grad(set_to_none=True)는 메모리를 절약하고, False는 기존 gradient 버퍼를 0으로 채웁니다.

기본 예제

optimizer = mt.optim.AdamW([
    {"params": model.backbone.parameters(), "lr": 1e-4},
    {"params": model.head.parameters(), "lr": 1e-3},
], weight_decay=0.01)

mytorch.optim.Optimizer

dense GPU Parameter 그룹과 optimizer state의 공통 생명주기를 관리합니다.

Signature
mytorch.optim.Optimizer(params: 'Iterable[Any]', defaults: 'dict[str, Any]') -> 'None'

파라미터

인자타입기본값설명
params'Iterable[Any]'필수최적화할 Parameter iterable 또는 parameter-group dict iterable입니다.
defaults'dict[str, Any]'필수모든 parameter group에 적용할 optimizer 기본 옵션 dict입니다.

반환값

설정된 Optimizer 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • optimizer state와 모든 update는 Parameter가 있는 CUDA 장치에서 계산됩니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
