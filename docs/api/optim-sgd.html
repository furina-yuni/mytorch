Optimization · mytorch.optim.sgd

SGD

기본 stochastic gradient descent, momentum, dampening, Nesterov, L2 weight decay를 설명합니다.

MyTorch 0.8.02개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • momentum=0이면 state buffer 없이 가장 단순한 update를 수행합니다.
  • nesterov=True는 momentum>0이고 dampening=0일 때만 유효합니다.
  • weight_decay는 gradient에 L2 항을 더하는 coupled decay입니다.

기본 예제

optimizer = mt.optim.SGD(
    model.parameters(), lr=0.05, momentum=0.9, nesterov=True
)
optimizer.zero_grad()
loss.backward()
optimizer.step()

Signature

파라미터

인자타입기본값설명

반환값

설정된 SGD 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • optimizer state와 모든 update는 Parameter가 있는 CUDA 장치에서 계산됩니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
