Optimization · mytorch.optim.adaptive

Adagrad, RMSprop, Adadelta

누적 또는 이동 평균 제곱 gradient로 파라미터별 학습률을 조절하는 optimizer를 설명합니다.

MyTorch 0.7.06개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • Adagrad는 제곱 gradient를 계속 누적하므로 학습이 진행될수록 유효 학습률이 감소합니다.
  • RMSprop은 alpha 이동 평균을 사용하며 centered와 momentum 옵션을 제공합니다.
  • Adadelta는 gradient와 update의 제곱 이동 평균을 함께 사용해 scale을 보정합니다.

기본 예제

optimizer = mt.optim.RMSprop(
    model.parameters(), lr=1e-3, alpha=0.99,
    eps=1e-8, momentum=0.9, centered=False,
)
