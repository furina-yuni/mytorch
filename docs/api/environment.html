Runtime · mytorch.utils

설치 환경 진단

MyTorch·Python·CuPy·CUDA·GPU 정보를 수집해 설치 문제와 버그 보고에 사용합니다.

MyTorch 0.13.02개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • python -m mytorch.utils 명령은 사람이 읽기 좋은 환경 보고서를 출력합니다.
  • get_env_info()는 CUDA 초기화가 실패한 환경에서도 가능한 정보를 dict로 반환하고 오류 종류를 함께 기록합니다.
  • --json 옵션을 사용하면 자동화 도구에서 처리하기 쉬운 JSON 형식으로 출력합니다.

기본 예제

# PowerShell
python -m mytorch.utils
python -m mytorch.utils --json

# Python
import mytorch as mt
print(mt.utils.format_env_info())

인자타입기본값설명

반환값

연산 결과 Tensor. 별도 설명이 없으면 입력과 같은 CUDA 장치에 있고 autograd 연결을 유지합니다.

동작과 주의사항

  • broadcasting과 dtype 승격은 지원 범위 안에서 CuPy 규칙을 따릅니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
