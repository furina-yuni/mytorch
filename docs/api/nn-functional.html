함수형 신경망 API

상태를 보관하지 않는 활성화, 선형·임베딩·정규화·합성곱·attention·손실 함수를 한곳에서 설명합니다.

MyTorch 0.7.085개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 함수형 API는 Parameter를 자동 등록하지 않습니다. 학습 상태가 필요하면 대응하는 nn.Module 클래스를 사용합니다.
  • 대부분의 손실 함수는 reduction='none', 'mean', 'sum'을 지원하며 none은 원소별 또는 sample별 손실을 유지합니다.
  • softmax, log_softmax, BCEWithLogits, focal loss는 극단값에서도 overflow를 줄이는 안정적인 수식을 사용합니다.

기본 예제

import mytorch as mt
+from mytorch.nn import functional as F

logits = mt.randn(32, 10, requires_grad=True)
target = mt.tensor([i % 10 for i in range(32)], dtype=mt.int64)
loss = F.cross_entropy(logits, target, label_smoothing=0.1)
loss.backward()
