Dataset과 DataLoader

입력과 라벨을 sample 단위로 매핑하고, GPU mini-batch로 효율적으로 묶어 학습 반복에 공급합니다.

MyTorch 0.9.08개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • TensorDataset은 같은 첫 번째 차원을 가진 GPU Tensor들을 sample 단위 tuple로 연결하며, DataLoader는 기본 경로에서 batch 전체를 GPU advanced indexing으로 한 번에 가져옵니다.
  • shuffle=True와 seed를 함께 사용하면 실행 간 순서를 재현하면서 epoch마다 새로운 순서를 만들 수 있고, drop_last=True는 크기가 작은 마지막 batch를 제외합니다.
  • 사용자 정의 Dataset은 __len__과 __getitem__을 구현합니다. default_collate는 Tensor, NumPy 배열, 숫자와 중첩 tuple·list·dict를 재귀적으로 GPU batch로 묶습니다.

기본 예제

import mytorch as mt

features = mt.randn(1000, 32)
labels = mt.tensor([index % 4 for index in range(1000)], dtype=mt.int64)
dataset = mt.data.TensorDataset(features, labels)
loader = mt.data.DataLoader(
    dataset, batch_size=64, shuffle=True, seed=2026
)

for batch_features, batch_labels in loader:
    optimizer.zero_grad()
    loss = criterion(model(batch_features), batch_labels)
    loss.backward()
    optimizer.step()

Class

mytorch.data.DataLoader

Dataset을 선택적으로 섞고 GPU mini-batch로 묶어 반복 가능한 loader입니다.

Signature
mytorch.data.DataLoader(dataset: 'Dataset[SampleT]', batch_size: 'int' = 1, shuffle: 'bool' = False, drop_last: 'bool' = False, collate_fn: 'CollateFn[SampleT, BatchT] | None' = None, *, seed: 'int | None' = None) -> 'None'

파라미터

인자타입기본값설명
dataset'Dataset[SampleT]'필수sample 개수와 정수 인덱싱을 제공하는 map-style Dataset입니다.
batch_size'int'1한 번의 반복에서 묶어 반환할 sample 수인 양의 정수입니다.
shuffle'bool'FalseTrue이면 각 epoch를 시작할 때 sample 인덱스 순서를 다시 섞습니다.
drop_last'bool'FalseTrue이면 dataset 크기가 batch_size로 나누어떨어지지 않을 때 작은 마지막 batch를 제외합니다.
collate_fn'CollateFn[SampleT, BatchT] | None'Nonesample 목록을 하나의 batch 구조로 결합하는 callable입니다. 생략하면 default_collate를 사용합니다.
seed'int | None'Noneshuffle 또는 random_split 순서를 재현할 Python 정수 seed입니다. None이면 비결정적 상태로 시작합니다.

반환값

재사용 가능한 DataLoader. 반복할 때마다 GPU mini-batch를 순서대로 생성합니다.

동작과 주의사항

  • TensorDataset의 기본 batch 경로는 sample별 Python loop 대신 GPU 정수 인덱싱을 사용합니다.
  • 멀티프로세스 worker와 pinned CPU memory는 GPU 전용 loader에서 지원하지 않습니다.
