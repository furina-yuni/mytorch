Dataset과 DataLoader

GPU Tensor와 실제 이미지·CSV·NPY 파일을 sample 단위로 매핑하고 sampler와 비동기 GPU 전송으로 mini-batch를 공급합니다.

MyTorch 0.12.025개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • TensorDataset은 같은 첫 번째 차원을 가진 GPU Tensor들을 sample 단위 tuple로 연결하며, DataLoader는 기본 경로에서 batch 전체를 GPU advanced indexing으로 한 번에 가져옵니다.
  • ImageFolder, CSVDataset, NpyDataset은 파일을 CPU에서 읽고 DataLoader가 batch 단위로 pinned memory를 거쳐 지정 CUDA 장치에 전송합니다.
  • num_workers는 Windows에서 안전한 thread worker 수이며 sampler, batch sampler, epoch와 무작위 순서는 state_dict로 복원할 수 있습니다.

기본 예제

import mytorch as mt

transform = mt.data.transforms.Compose([
    mt.data.transforms.Resize((224, 224)),
    mt.data.transforms.ToArray(),
    mt.data.transforms.Normalize([0.5] * 3, [0.5] * 3),
])
dataset = mt.data.ImageFolder("data/train", transform=transform)
loader = mt.data.DataLoader(
    dataset, batch_size=64, shuffle=True, num_workers=4,
    prefetch_factor=2, pin_memory=True, seed=2026,
)

mytorch.data.BatchSampler

다른 Sampler의 index를 고정 크기 mini-batch 목록으로 묶습니다.

Signature
mytorch.data.BatchSampler(sampler: 'Iterable[int]', batch_size: 'int', drop_last: 'bool') -> 'None'

파라미터

인자타입기본값설명
sampler'Iterable[int]'필수sample 인덱스의 순서와 선택 방법을 제공하는 Sampler입니다.
batch_size'int'필수한 번의 반복에서 묶어 반환할 sample 수인 양의 정수입니다.
drop_last'bool'필수True이면 dataset 크기가 batch_size로 나누어떨어지지 않을 때 작은 마지막 batch를 제외합니다.

반환값

설정된 BatchSampler 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • TensorDataset의 기본 batch 경로는 sample별 Python loop 대신 GPU 정수 인덱싱을 사용합니다.
  • 멀티프로세스 worker와 pinned CPU memory는 GPU 전용 loader에서 지원하지 않습니다.
