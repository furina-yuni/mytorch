모델 저장과 불러오기

Module.state_dict()를 안전한 NPZ와 JSON 메타데이터 형식으로 저장하고 원하는 CUDA 장치로 복원합니다.

MyTorch 0.7.02개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 저장할 때만 GPU Tensor가 NumPy 배열로 복사되며 임의 Python 객체 pickle은 사용하지 않습니다.
  • load()는 OrderedDict[str, Tensor]를 반환하므로 모델의 load_state_dict()에 전달합니다.
  • 구조가 같은 모델을 먼저 생성한 뒤 strict 검증을 통해 shape와 dtype 불일치를 찾습니다.

기본 예제

import mytorch as mt

mt.save(model.state_dict(), "checkpoint.npz")
state = mt.load("checkpoint.npz", device="cuda:0")
model.load_state_dict(state)

Function

mytorch.load

저장된 NPZ state mapping을 지정 CUDA 장치의 Tensor로 복원합니다.

Signature
mytorch.load(path: 'str | Path', device: 'str | int' = 'cuda:0') -> 'OrderedDict[str, Tensor]'

파라미터

인자타입기본값설명
path'str | Path'필수읽거나 쓸 NPZ 파일 경로입니다.
device'str | int''cuda:0'CUDA 장치입니다. 'cuda:N' 문자열 또는 정수 N을 사용하며 기본값은 cuda:0입니다.

반환값

이름과 GPU Tensor를 연결한 순서 보존 mapping입니다.

동작과 주의사항

  • broadcasting과 dtype 승격은 지원 범위 안에서 CuPy 규칙을 따릅니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
Function

mytorch.save

Tensor state mapping을 NPZ 배열과 JSON 메타데이터로 저장합니다.

Signature
mytorch.save(state_dict: 'Mapping[str, Tensor]', path: 'str | Path') -> 'None'

파라미터

인자타입기본값설명
state_dict'Mapping[str, Tensor]'필수파라미터와 persistent buffer 이름을 Tensor에 대응시킨 mapping입니다.
path'str | Path'필수읽거나 쓸 NPZ 파일 경로입니다.

반환값

None. 객체의 gradient, 난수 상태, 파일 또는 Parameter를 변경합니다.

동작과 주의사항

  • broadcasting과 dtype 승격은 지원 범위 안에서 CuPy 규칙을 따릅니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
