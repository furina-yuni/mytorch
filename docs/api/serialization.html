모델과 학습 체크포인트

모델 state 또는 optimizer·DataLoader·GPU RNG를 포함한 전체 학습 상태를 안전한 NPZ와 JSON 메타데이터 형식으로 저장합니다.

MyTorch 0.13.06개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 저장할 때만 GPU Tensor가 NumPy 배열로 복사되며 임의 Python 객체 pickle은 사용하지 않습니다.
  • load()는 모델 전용 Tensor mapping을 반환하고, load_checkpoint()는 중첩된 전체 학습 상태를 지정 CUDA 장치로 복원합니다.
  • optimizer, scheduler, GradScaler와 DataLoader의 state_dict, get_rng_state()를 함께 저장하면 epoch 경계에서 학습 상태를 정확히 이어갈 수 있습니다.

기본 예제

import mytorch as mt

mt.save_checkpoint({
    "epoch": epoch,
    "model": model.state_dict(),
    "optimizer": optimizer.state_dict(),
    "scheduler": scheduler.state_dict(),
    "scaler": scaler.state_dict(),
    "dataloader": loader.state_dict(),
    "rng_state": mt.get_rng_state(),
}, "training.mtz")

state = mt.load_checkpoint("training.mtz")
model.load_state_dict(state["model"])
optimizer.load_state_dict(state["optimizer"])
scheduler.load_state_dict(state["scheduler"])
scaler.load_state_dict(state["scaler"])
loader.load_state_dict(state["dataloader"])
mt.set_rng_state(state["rng_state"])

mytorch.get_rng_state

MyTorch가 관리하는 장치별 GPU 난수 stream 위치를 반환합니다.

Signature
mytorch.get_rng_state() -> 'dict[str, Any]'

파라미터

별도 인자가 없습니다.

반환값

장치별 seed와 다음 난수 호출 위치를 담은 안전한 Python mapping입니다.

동작과 주의사항

  • 파일 메타데이터와 값 타입을 검증하며 임의 Python 객체를 pickle로 실행하지 않습니다.
  • Tensor를 저장하고 불러올 때만 GPU와 CPU 사이에 명시적인 복사가 일어납니다.
