FP16 자동 혼합정밀도

FP32 master Parameter를 유지하면서 행렬곱과 합성곱을 FP16으로 실행하고 동적 loss scaling으로 overflow를 제어합니다.

MyTorch 0.12.011개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • autocast는 Linear·행렬곱·합성곱을 FP16으로 실행하지만 softmax, loss, normalization과 주요 reduction은 FP32로 유지합니다.
  • GradScaler는 backward 전에 loss를 확대하고 optimizer 직전에 gradient를 복원합니다. NaN이나 Inf가 있으면 해당 update를 안전하게 건너뜁니다.
  • step()이 True를 반환했을 때만 batch 단위 scheduler를 진행해야 overflow 이후 learning-rate schedule이 어긋나지 않습니다.

기본 예제

scaler = mt.amp.GradScaler()

optimizer.zero_grad()
with mt.amp.autocast():
    loss = criterion(model(inputs), targets)
scaler.scale(loss).backward()
updated = scaler.step(optimizer)
scaler.update()
if updated:
    scheduler.step()

Class

mytorch.amp.GradScaler

loss scale을 동적으로 조절하고 비정상 gradient의 optimizer step을 건너뜁니다.

Signature
mytorch.amp.GradScaler(init_scale: 'float' = 65536.0, growth_factor: 'float' = 2.0, backoff_factor: 'float' = 0.5, growth_interval: 'int' = 2000, enabled: 'bool' = True) -> 'None'

파라미터

인자타입기본값설명
init_scale'float'65536.0GradScaler가 처음 loss에 곱할 배율입니다.
growth_factor'float'2.0안정적인 step이 누적됐을 때 scale에 곱할 값입니다.
backoff_factor'float'0.5overflow 발생 시 scale에 곱할 1 미만의 값입니다.
growth_interval'int'2000scale을 증가시키기 전에 필요한 연속 정상 step 수입니다.
enabled'bool'TrueTrue이면 현재 문맥에서 계산 그래프 기록을 활성화하고 False이면 비활성화합니다.

반환값

설정된 GradScaler 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
