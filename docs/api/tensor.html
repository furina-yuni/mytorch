Tensor와 기본 연산

GPU 메모리에 데이터를 보관하는 Tensor, 생성 함수, 수학·축소·형태·인덱싱·선형대수 연산을 설명합니다.

MyTorch 0.7.0126개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 모든 수치 데이터는 cupy.ndarray로 CUDA 장치에 유지됩니다. numpy()와 item()만 명시적으로 CPU로 복사합니다.
  • 기본 dtype은 float32이며, 서로 다른 GPU의 Tensor를 한 연산에 섞으면 오류가 발생합니다.
  • requires_grad=True인 실수 Tensor는 동적 계산 그래프를 만들고 backward()에서 gradient를 누적합니다.

기본 예제

import mytorch as mt

x = mt.arange(6, dtype=mt.float32).reshape(2, 3)
w = mt.randn(3, 4, requires_grad=True)
y = (x @ w).relu()
loss = y.mean()
loss.backward()
print(y.shape, w.grad.shape)

mytorch.Tensor

파라미터

dtype'DTypeLike | None'None결과 또는 파라미터의 dtype입니다. 생략 시 생성 규칙 또는 입력 dtype을 따릅니다.
