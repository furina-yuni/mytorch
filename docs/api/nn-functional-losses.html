Functional · mytorch.nn.functional

함수형 손실 연산

회귀·분류·분포·ranking·metric·segmentation 손실의 입력 shape와 reduction 규칙을 설명합니다.

MyTorch 0.13.021개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 대부분의 손실은 reduction='none', 'mean', 'sum'을 지원하며 KLDiv는 'batchmean'도 제공합니다.
  • BCEWithLogits, focal, log-softmax 기반 분류 손실은 큰 양수·음수 logits에서도 안정적인 식을 사용합니다.
  • target dtype과 shape 규칙은 손실마다 다르므로 각 API의 파라미터와 주의사항을 확인하십시오.

기본 예제

import mytorch as mt
from mytorch.nn import functional as F

logits = mt.randn(32, 10, requires_grad=True)
target = mt.tensor([i % 10 for i in range(32)], dtype=mt.int64)
loss = F.cross_entropy(logits, target, label_smoothing=0.1)
loss.backward()

Function

mytorch.nn.functional.mse_loss

prediction과 target의 제곱 오차를 계산합니다.

Signature
mytorch.nn.functional.mse_loss(input: 'Tensor', target: 'Tensor', reduction: 'str' = 'mean') -> 'Tensor'

파라미터

인자타입기본값설명
input'Tensor'필수연산에 전달할 입력 Tensor입니다. 명시된 shape와 floating dtype 조건을 만족해야 합니다.
target'Tensor'필수정답 또는 목표 Tensor입니다. 손실별로 class index 또는 입력과 같은 shape의 값이 필요합니다.
reduction'str''mean'손실 집계 방식입니다. 일반적으로 'none', 'mean', 'sum' 중 하나입니다.

반환값

연산 결과 Tensor. 별도 설명이 없으면 입력과 같은 CUDA 장치에 있고 autograd 연결을 유지합니다.

동작과 주의사항

  • reduction='none'은 축소 전 손실을, 'mean'과 'sum'은 scalar 손실을 반환합니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
