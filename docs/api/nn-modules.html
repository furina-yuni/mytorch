Module, 컨테이너, 활성화·손실 클래스

학습 가능한 Parameter의 재귀 등록, 모델 모드, 상태 관리, 기본 Linear와 클래스형 활성화·손실 API를 다룹니다.

MyTorch 0.7.078개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • Module 속성에 Parameter나 자식 Module을 대입하면 자동 등록되어 parameters()와 state_dict()에 포함됩니다.
  • train()과 eval()은 모든 자식 모듈로 재귀 전파됩니다. Dropout, BatchNorm, RReLU처럼 모드 의존적인 계층에 중요합니다.
  • 손실 클래스는 함수형 손실의 설정을 생성자에 보관하고 forward에서 prediction과 target을 받습니다.

기본 예제

import mytorch as mt

model = mt.nn.Sequential(
    mt.nn.Linear(8, 32),
    mt.nn.GELU(),
    mt.nn.Linear(32, 4),
)
criterion = mt.nn.CrossEntropyLoss()
logits = model(mt.randn(16, 8))
target = mt.tensor([0, 1, 2, 3] * 4, dtype=mt.int64)
loss = criterion(logits, target)
