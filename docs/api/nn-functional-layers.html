함수형 계층 연산

Parameter 상태를 보관하지 않는 선형·임베딩·정규화·dropout·합성곱·pooling·attention 연산입니다.

MyTorch 0.13.031개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 함수형 계층은 weight와 bias를 직접 인자로 받으며 Parameter를 자동 등록하지 않습니다.
  • 학습 가능한 상태나 train/eval 전환이 필요하면 대응하는 nn.Module 클래스를 사용하는 편이 안전합니다.
  • 입력, weight, mask는 같은 CUDA 장치에 있어야 하며 장치 사이 암묵적 복사를 하지 않습니다.

기본 예제

import mytorch as mt
from mytorch.nn import functional as F

x = mt.randn(8, 32)
weight = mt.randn(64, 32, requires_grad=True)
bias = mt.zeros(64, requires_grad=True)
y = F.linear(x, weight, bias)

mytorch.nn.functional.linear

GPU Tensor에 linear 연산을 적용합니다.

Signature
mytorch.nn.functional.linear(input: 'Tensor', weight: 'Tensor', bias: 'Tensor | None' = None) -> 'Tensor'

파라미터

인자타입기본값설명
input'Tensor'필수연산에 전달할 입력 Tensor입니다. 명시된 shape와 floating dtype 조건을 만족해야 합니다.
weight'Tensor'필수원소별·class별 가중치 또는 계층의 학습 가능한 weight Tensor입니다.
bias'Tensor | None'NoneTrue이면 학습 가능한 bias Parameter를 추가합니다.

반환값

연산 결과 Tensor. 별도 설명이 없으면 입력과 같은 CUDA 장치에 있고 autograd 연결을 유지합니다.

동작과 주의사항

  • broadcasting과 dtype 승격은 지원 범위 안에서 CuPy 규칙을 따릅니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
