Optimization · mytorch.optim.adam

Adam 계열

Adam, AdamW, Adamax, NAdam, RAdam의 moment state, bias correction, weight decay 차이를 설명합니다.

MyTorch 0.7.09개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • Adam은 1차·2차 지수 이동 평균과 bias correction을 사용합니다.
  • AdamW는 gradient moment와 분리된 decoupled weight decay를 적용합니다.
  • NAdam은 Nesterov momentum을, RAdam은 초기 second moment 분산을 rectification합니다.

기본 예제

optimizer = mt.optim.AdamW(
    model.parameters(), lr=3e-4, betas=(0.9, 0.999),
    eps=1e-8, weight_decay=0.01,
)

Class

mytorch.optim.Adam

1차·2차 moment의 지수 이동 평균과 bias correction으로 Parameter를 갱신합니다.

Signature
mytorch.optim.Adam(params: 'Iterable[Any]', lr: 'float' = 0.001, betas: 'tuple[float, float]' = (0.9, 0.999), eps: 'float' = 1e-08, weight_decay: 'float' = 0.0, amsgrad: 'bool' = False, maximize: 'bool' = False) -> 'None'

파라미터

인자타입기본값설명
params'Iterable[Any]'필수최적화할 Parameter iterable 또는 parameter-group dict iterable입니다.
lr'float'0.001optimizer learning rate입니다. 양수여야 합니다.
betas'tuple[float, float]'(0.9, 0.999)moment 추정에 사용하는 두 지수 감쇠 계수의 tuple입니다.
eps'float'1e-080으로 나누거나 매우 작은 값에서 불안정해지는 것을 막는 양의 상수입니다.
weight_decay'float'0.0가중치 감쇠 계수입니다. optimizer에 따라 coupled 또는 decoupled 방식입니다.
amsgrad'bool'FalseTrue이면 과거 second moment 최댓값을 유지하는 AMSGrad 변형을 사용합니다.
maximize'bool'FalseTrue이면 목적함수를 최소화하지 않고 최대화하는 방향으로 갱신합니다.

반환값

동작과 주의사항

  • optimizer state와 모든 update는 Parameter가 있는 CUDA 장치에서 계산됩니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
