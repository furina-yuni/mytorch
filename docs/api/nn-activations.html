Neural network · mytorch.nn.modules

활성화 함수 Module

ReLU 계열, smooth activation, shrink 함수와 GLU 계열을 클래스형 API로 분리해 설명합니다.

MyTorch 0.7.030개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • Module형 활성화는 생성자 설정을 보관하므로 Sequential 안에 바로 등록할 수 있습니다.
  • PReLU만 학습 가능한 Parameter를 가지며 RReLU는 train/eval 모드에 따라 slope 생성 방식이 달라집니다.
  • GLU 계열은 지정 축을 둘로 나누므로 해당 축 크기가 짝수여야 하고 출력 크기는 절반이 됩니다.

기본 예제

import mytorch as mt

activation = mt.nn.GELU(approximate="tanh")
x = mt.randn(32, 128, requires_grad=True)
y = activation(x)
y.mean().backward()

Signature
mytorch.nn.ReLU() -> 'None'

파라미터

별도 인자가 없습니다.

반환값

설정된 ReLU 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • float16, float32, float64 입력을 지원하고 결과 dtype과 shape를 유지합니다.
