CUDA 연산 Profiler

CUDA event로 MyTorch 연산별 GPU 실행 시간을 측정하고 호출 횟수와 평균을 집계합니다.

MyTorch 0.13.06개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • profile context 안에서 _ops 실행 계층을 통과한 연산을 기록하므로 Tensor 산술과 대부분의 신경망 연산을 한 흐름으로 분석할 수 있습니다.
  • record_shapes=True이면 GPU 데이터를 CPU로 복사하지 않고 입력 shape 메타데이터만 함께 기록합니다.
  • events(), key_averages(), summary()는 context가 끝나 CUDA event가 완료된 뒤 사용할 수 있습니다.

기본 예제

import mytorch as mt

x = mt.randn(512, 512)
w = mt.randn(512, 512)
with mt.profiler.profile(record_shapes=True) as prof:
    output = (x @ w).relu().sum()

print(prof.summary())

Class

mytorch.profiler.FunctionEvent

한 번 실행된 GPU 연산의 이름, 장치, CUDA 시간과 입력 shape 기록입니다.

Signature
mytorch.profiler.FunctionEvent(name: 'str', device: 'int', cuda_time_ms: 'float', input_shapes: 'tuple[tuple[int, ...], ...]') -> None

파라미터

인자타입기본값설명
name'str'필수등록하거나 조회할 이름입니다. 점(.)이 없는 비어 있지 않은 문자열이어야 합니다.
device'int'필수CUDA 장치입니다. 'cuda:N' 문자열 또는 정수 N을 사용하며 기본값은 cuda:0입니다.
cuda_time_ms'float'필수개별 연산이 GPU에서 실행된 CUDA event 기준 시간(ms)입니다.
input_shapes'tuple[tuple[int, ...], ...]'필수profiler가 기록한 Tensor 입력 shape tuple입니다.

반환값

설정된 FunctionEvent 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
