Data · mytorch.data.transforms

이미지 Transform

이미지를 CPU에서 resize·crop·flip하고 CHW float32 배열로 변환·정규화하는 조합 가능한 전처리 API입니다.

MyTorch 0.13.07개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 기하 transform을 먼저 적용한 다음 ToArray로 CHW float32 배열을 만들고 마지막에 Normalize를 적용합니다.
  • RandomCrop과 RandomHorizontalFlip은 DataLoader가 sample별 seed를 제공하므로 worker 완료 순서와 무관하게 재현됩니다.
  • transform은 worker에서 실행되며 GPU Tensor 생성은 batch collate와 main-thread 전송 단계에서만 일어납니다.

기본 예제

from mytorch.data import transforms

train_transform = transforms.Compose([
    transforms.Resize((256, 256)),
    transforms.RandomCrop((224, 224)),
    transforms.RandomHorizontalFlip(),
    transforms.ToArray(),
    transforms.Normalize([0.485, 0.456, 0.406],
                         [0.229, 0.224, 0.225]),
])

Signature

파라미터

반환값

설정된 CenterCrop 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • TensorDataset의 기본 batch 경로는 sample별 Python loop 대신 GPU 정수 인덱싱을 사용합니다.
  • 멀티프로세스 worker와 pinned CPU memory는 GPU 전용 loader에서 지원하지 않습니다.
