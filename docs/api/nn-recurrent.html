Sequence · mytorch.nn.recurrent

RNN, GRU, LSTM

단일 step 셀과 다층·양방향 recurrent 계층의 입력, hidden state, 반환 shape를 설명합니다.

MyTorch 0.8.09개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • batch_first=False 입력은 (시간, 배치, 특성), True 입력은 (배치, 시간, 특성)입니다.
  • 출력 hidden의 첫 축 크기는 num_layers × num_directions입니다.
  • LSTM은 (hidden, cell) 튜플을 사용하고 RNN·GRU는 hidden Tensor 하나를 사용합니다.

기본 예제

import mytorch as mt

gru = mt.nn.GRU(24, 48, num_layers=2, batch_first=True)
sequence = mt.randn(16, 20, 24)
output, hidden = gru(sequence)
print(output.shape, hidden.shape)
