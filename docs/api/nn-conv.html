Convolution과 Pooling

1D·2D·3D 합성곱, 전치 합성곱, 고정·적응형 pooling 계층의 입력 shape와 공간 크기 계산을 설명합니다.

MyTorch 0.7.018개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • ConvNd 입력은 (N, C, 공간축...) 형식이며 groups는 in_channels와 out_channels를 모두 나누어야 합니다.
  • padding, stride, dilation은 정수 또는 공간 차원 수와 같은 길이의 tuple을 허용합니다.
  • MaxPool은 argmax 위치로 gradient를 되돌리고 AvgPool은 padding을 분모에 포함합니다.

기본 예제

import mytorch as mt

net = mt.nn.Sequential(
    mt.nn.Conv2d(3, 16, 3, padding=1),
    mt.nn.ReLU(),
    mt.nn.MaxPool2d(2),
    mt.nn.Conv2d(16, 32, 3, padding=1),
    mt.nn.AdaptiveAvgPool2d((1, 1)),
    mt.nn.Flatten(),
    mt.nn.Linear(32, 10),
)
y = net(mt.randn(8, 3, 32, 32))

GPU im2col과 matrix multiplication으로 N차원 합성곱을 수행하는 계층입니다.

Signature
mytorch.nn.Conv1d(in_channels: 'int', out_channels: 'int', kernel_size: 'int | Sequence[int]', stride: 'int | Sequence[int]' = 1, padding: 'int | Sequence[int]' = 0, output_padding: 'int | Sequence[int]' = 0, groups: 'int' = 1, bias: 'bool' = True, dilation: 'int | Sequence[int]' = 1, *, device: 'str | int' = 'cuda:0', dtype: 'Any' = <class 'numpy.float32'>) -> 'None'

인자타입기본값설명
in_channels'int'필수입력 Tensor의 channel 수입니다.

kernel_size'int | Sequence[int]'필수공간 kernel 크기입니다. 정수 또는 차원별 tuple을 허용합니다.
stride'int | Sequence[int]'1kernel이 이동하는 간격입니다. 생략 가능한 pooling에서는 kernel_size를 사용합니다.

output_padding'int | Sequence[int]'0전치 합성곱의 모호한 출력 공간 크기를 조정하는 추가 크기입니다.

bias'bool'TrueTrue이면 학습 가능한 bias Parameter를 추가합니다.
dilation'int | Sequence[int]'1kernel 원소 사이 간격입니다.

동작과 주의사항

  • 입력은 batch와 channel 축 뒤에 1~3개의 공간축을 갖습니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
