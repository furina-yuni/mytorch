함수형 활성화 연산

상태 없는 활성화 함수를 수식 계열별로 모아 입력·인자·gradient 규칙을 설명합니다.

MyTorch 0.13.030개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 함수형 활성화는 입력 Tensor를 변경하지 않고 같은 shape의 새 Tensor를 반환합니다.
  • softmax와 log_softmax는 지정 축에서 계산하며 GELU는 exact와 tanh 근사를 선택할 수 있습니다.
  • prelu의 weight만 외부 학습 Parameter를 받고 rrelu는 training 인자에 따라 무작위 slope를 사용합니다.

기본 예제

import mytorch as mt
from mytorch.nn import functional as F

x = mt.tensor([-2.0, 0.0, 2.0], requires_grad=True)
y = F.mish(x) + F.gelu(x, approximate="tanh")
y.sum().backward()

Function

mytorch.nn.functional.relu

음수는 0, 양수는 그대로 두는 ReLU 활성화를 적용합니다.

Signature
mytorch.nn.functional.relu(input: 'Tensor') -> 'Tensor'

파라미터

인자타입기본값설명
input'Tensor'필수연산에 전달할 입력 Tensor입니다. 명시된 shape와 floating dtype 조건을 만족해야 합니다.

반환값

연산 결과 Tensor. 별도 설명이 없으면 입력과 같은 CUDA 장치에 있고 autograd 연결을 유지합니다.

동작과 주의사항

  • float16, float32, float64 입력을 지원하고 결과 dtype과 shape를 유지합니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
