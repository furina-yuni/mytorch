Optimization · mytorch.optim.lr_scheduler

Learning Rate Scheduler

epoch·batch·검증 metric에 따라 optimizer parameter group의 learning rate를 재현 가능하게 조절합니다.

MyTorch 0.13.028개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 일반 scheduler는 optimizer 갱신 뒤 step()을 호출하며 ReduceLROnPlateau만 검증 metric을 step(metric)에 전달합니다.
  • LinearLR와 SequentialLR을 조합하면 warm-up 뒤 cosine 또는 exponential decay를 구성할 수 있습니다.
  • scheduler state_dict에는 현재 위치와 group별 LR이 포함되어 checkpoint 복원 후 다음 step을 정확히 이어갑니다.

기본 예제

optimizer = mt.optim.AdamW(model.parameters(), lr=3e-4)
warmup = mt.optim.LinearLR(optimizer, start_factor=0.1, total_iters=5)
cosine = mt.optim.CosineAnnealingLR(optimizer, T_max=95)
scheduler = mt.optim.SequentialLR(
    optimizer, [warmup, cosine], milestones=[5]
)

for epoch in range(100):
    train_one_epoch()
    scheduler.step()
