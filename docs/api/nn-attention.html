Transformer · mytorch.nn.modules

Attention, Transformer, RoPE

Scaled dot-product attention, multi-head projection, Transformer Encoder, rotary position embedding을 설명합니다.

MyTorch 0.12.07개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • boolean mask의 True는 허용 위치, False는 차단 위치입니다. additive mask는 attention score에 직접 더합니다.
  • 완전히 마스킹된 query 행은 NaN 대신 0 출력을 생성합니다.
  • TransformerEncoderLayer는 pre/post norm, ReLU/GELU, 일반 FFN 또는 SwiGLU FFN을 선택할 수 있습니다.

기본 예제

import mytorch as mt

layer = mt.nn.TransformerEncoderLayer(
    d_model=128, nhead=8, dim_feedforward=512,
    batch_first=True, norm_first=True, activation="gelu",
)
encoder = mt.nn.TransformerEncoder(layer, num_layers=4)
x = mt.randn(2, 32, 128)
y = encoder(x)
