LoRA, 양자화, BitNet, MoE

저랭크 적응, 추론용 INT8·INT4, QAT용 BitLinear, 2-bit packed 추론, sparse mixture-of-experts 계층을 다룹니다.

MyTorch 0.9.018개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • LoRALinear는 base 경로와 A·B 저랭크 경로를 분리하며 merge()/unmerge()는 반복 호출에도 안전합니다.
  • Int8Linear, Int4WeightOnlyLinear, PackedBitLinear은 추론 전용이며 requires_grad 입력을 거부합니다.
  • SparseMoE는 top-k expert만 실행하고 출력과 load-balancing auxiliary loss를 함께 반환합니다.

기본 예제

import mytorch as mt

qat = mt.nn.BitLinear(256, 128, rms_norm=True)
y_train = qat(mt.randn(32, 256))
packed = qat.to_inference()
with mt.no_grad():
    y_infer = packed(mt.randn(32, 256))
print(packed.compression_ratio)
