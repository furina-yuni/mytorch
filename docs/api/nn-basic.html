임베딩, Dropout, 정규화

Bilinear와 LazyLinear, 임베딩, 확률적 정규화, Batch·Layer·RMS·Group·Instance 정규화 계층을 설명합니다.

MyTorch 0.7.019개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • Embedding은 int32 또는 int64 인덱스를 받아 마지막 축에 embedding_dim을 추가하며 중복 인덱스의 gradient를 scatter-add합니다.
  • Dropout 계열은 training 모드에서만 마스크를 적용하고 eval 모드에서는 입력을 그대로 반환합니다.
  • BatchNorm의 running 통계는 persistent buffer이므로 state_dict에 저장되지만 optimizer의 파라미터는 아닙니다.

기본 예제

import mytorch as mt

embedding = mt.nn.Embedding(1000, 64, padding_idx=0)
norm = mt.nn.LayerNorm(64)
dropout = mt.nn.Dropout(0.1)
ids = mt.tensor([[1, 4, 9], [2, 0, 3]], dtype=mt.int64)
x = dropout(norm(embedding(ids)))
