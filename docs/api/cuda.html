CUDA 상태 확인

NVIDIA GPU와 CUDA 런타임의 가용성 및 장치 수를 확인하는 최소 인터페이스입니다.

MyTorch 0.7.03개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • is_available()은 CUDA 런타임 초기화와 장치 접근 가능 여부를 함께 확인합니다.
  • GPU를 사용할 수 없을 때 MyTorch는 CPU로 자동 전환하지 않습니다.
  • device_count()의 결과는 cuda:0부터 시작하는 유효 장치 인덱스의 개수입니다.

기본 예제

import mytorch as mt

if not mt.cuda.is_available():
    raise RuntimeError("CUDA GPU가 필요합니다")
print("GPU 개수:", mt.cuda.device_count())

파라미터

별도 인자가 없습니다.

반환값

설정된 CudaUnavailableError 인스턴스. Parameter와 buffer는 지정 CUDA 장치에 생성됩니다.

동작과 주의사항

  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
