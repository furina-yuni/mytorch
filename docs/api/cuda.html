Runtime · mytorch.cuda

CUDA 상태 확인

NVIDIA GPU 가용성, 동기화, CuPy memory pool과 물리 장치 메모리 상태를 확인합니다.

MyTorch 0.13.014개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • is_available()은 CUDA 런타임 초기화와 장치 접근 가능 여부를 함께 확인합니다.
  • memory_allocated()와 memory_reserved()는 현재 배열 및 CuPy pool 사용량을, memory_stats()는 peak와 물리 장치 여유량까지 반환합니다.
  • empty_cache()는 사용 중인 Tensor를 삭제하지 않고 pool의 미사용 block만 CUDA runtime으로 반환합니다.

기본 예제

import mytorch as mt

if not mt.cuda.is_available():
    raise RuntimeError("CUDA GPU가 필요합니다")

x = mt.randn(1024, 1024)
mt.cuda.synchronize()
print(mt.cuda.memory_summary())
