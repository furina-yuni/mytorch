자동미분과 gradient 모드

동적 계산 그래프, 역전파, gradient 누적, no_grad 컨텍스트의 사용 규칙을 설명합니다.

MyTorch 0.7.09개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 스칼라 결과는 gradient를 생략할 수 있지만 비스칼라 결과는 같은 shape와 device의 gradient가 필요합니다.
  • 기본 backward는 그래프를 해제합니다. 같은 그래프를 다시 사용할 때는 첫 호출에 retain_graph=True를 지정합니다.
  • optimizer 갱신은 no_grad 상태에서 수행되며, forward 뒤 변경된 Tensor를 사용하는 backward는 version 검사로 거부됩니다.

기본 예제

import mytorch as mt

x = mt.tensor([1.0, 2.0, 3.0], requires_grad=True)
y = (x.square() * 2).sum()
y.backward()
print(x.grad.numpy())

with mt.no_grad():
    prediction = x * 3
