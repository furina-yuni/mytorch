파라미터 초기화

상수·균등·정규 분포와 Xavier·Kaiming 초기화로 Parameter 값을 GPU에서 설정합니다.

MyTorch 0.7.07개 API 항목CUDA 전용

이 모듈을 사용할 때 알아둘 점

  • 초기화 함수는 전달받은 Tensor를 직접 변경해 같은 객체를 반환하고 version counter를 증가시킵니다.
  • Xavier는 fan_in과 fan_out을 함께, Kaiming은 선택한 mode에 따라 하나의 fan을 사용합니다.
  • optimizer를 만들기 전에 초기화하고, 이미 forward에 사용한 Tensor는 초기화 뒤 그 그래프로 backward하지 마십시오.

기본 예제

import mytorch as mt
from mytorch.nn import init

layer = mt.nn.Linear(128, 64)
init.kaiming_uniform_(layer.weight, a=0.01, nonlinearity="leaky_relu")
init.constant_(layer.bias, 0.0)

Function

mytorch.nn.init.constant_

GPU Tensor에 constant_ 연산을 적용합니다.

Signature
mytorch.nn.init.constant_(tensor: 'Tensor', value: 'float') -> 'Tensor'

파라미터

인자타입기본값설명
tensor'Tensor'필수초기화하거나 buffer로 등록할 Tensor입니다.
value'float'필수attention의 value Tensor 또는 채울 스칼라 값입니다.

반환값

연산 결과 Tensor. 별도 설명이 없으면 입력과 같은 CUDA 장치에 있고 autograd 연결을 유지합니다.

동작과 주의사항

  • broadcasting과 dtype 승격은 지원 범위 안에서 CuPy 규칙을 따릅니다.
  • 실수 입력이 requires_grad=True이고 gradient 모드가 켜져 있으면 backward 그래프를 기록합니다.
  • 잘못된 dtype, device, shape, 축 또는 범위 값은 자동 보정하지 않고 명확한 예외로 거부합니다.
